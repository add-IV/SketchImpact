# Recommended Papers for a Semester Project

If you're implementing **AI-assisted collision detection in a game**, these are the best references to cite:

1. DeepCollide (2023)
2. Neural Collision Detection for Deformable Objects (2022)
3. LCollision (2020)
4. Neural Collision Fields (2023)
5. A Neural Network Approach for Real-Time Collision Detection (2002)

These papers all explore using machine learning to predict, approximate, or accelerate collision detection rather than relying solely on traditional geometric algorithms.
