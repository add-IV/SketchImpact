# SketchImpact

CNN-filtered collision detection for freeform sprites in a 2D billiard game.

**Report is available at: [documentation/report.pdf](documentation/report.pdf)**
(source: [documentation/report.md](documentation/report.md))

## Quick start

- Game: open in Godot 4.7, press **F5**.
- sprites: extract sprites.zip to /sprites to use scenario 2 (press 2 in game)
- CNN filter: install [uv](https://docs.astral.sh/uv/) and it auto-starts with the game.
- without uv, you will need to update collision_model.gd to use your python version
